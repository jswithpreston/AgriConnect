## Demo Instructions for Presentation

1. **Open the app** — splash screen loads for ~2 seconds
2. **Onboarding** — swipe through 3 slides, tap "Get Started"
3. **Login screen** — tap **"Demo Farmer"** or **"Demo Buyer"** button
4. **Home screen** — shows greeting, quick actions, weather card, listings feed
5. **Browse tab** — 8 real crop listings with images and prices
6. **Map tab** — interactive map with all listing pins
7. **Messages tab** — 3 pre-loaded conversations
8. **Profile tab** — user profile with stats and settings
9. **Logout** — Profile → Logout → returns to login screen

---

## Recommended Demo Flow

**For Farmer role:**
Login → Home → Create Listing → My Listings → Chat → Weather → Profile

**For Buyer role:**
Login → Home → Browse Listings → Listing Detail → Contact Farmer → Chat → Map → Profile
